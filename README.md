# Movie Revenue Prediction Analysis

## Overview

This project explores movie metadata to predict revenue using various statistical and machine learning techniques. The analysis involves data cleaning, visualization, and model building to understand factors influencing movie profitability.

## Libraries Used

This project utilizes several R libraries:

- `ggplot2`: For data visualization
- `dplyr`: For data manipulation
- `DT`: For displaying data tables
- `tidyverse`: A collection of R packages for data science
- `wordcloud`: For generating word clouds
- `tm`: For text mining
- `reshape2`: For reshaping data
- `caTools`: For data splitting
- `class`: For K-Nearest Neighbors (KNN) classification
- `randomForest`: For Random Forest regression

## Data Source

The dataset used in this analysis is contained in `movie_metadata.csv`, which includes various attributes of movies such as budget, gross revenue, IMDb scores, and more.
